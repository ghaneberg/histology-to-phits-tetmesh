# histology-to-phits-tetmesh

Histology label volume -> conforming PHITS tetrahedral mesh

Reusable code from the author's doctoral research at the University of Florida
(Medical Physics, ALRADS / Bolch group). **No research histology, mesh, or PHITS
data is shipped with this repository** — code and tooling only, with synthetic
demo data so the pipeline can be exercised without any UF-acquired images.

See `docs/` for methods notes. MIT licensed (see `LICENSE`).
